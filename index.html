Concept


ReactION visualizes your React app's component tree right inside VS Code and Cursor, two ways: an instant static composition tree built straight from your source — no dev server, no browser, no setup — and an opt-in live mode that drives a real Chrome instance and streams an interactive graph with render counts, wasted-render detection, and live DOM highlighting.
To install, open the Extensions view in either editor (Cmd+Shift+X on macOS, Ctrl+Shift+X on Windows/Linux) and search for ReactION — or jump straight to the listing with the VS Code or Cursor buttons above.

Demo


Static Analysis

Click "Launch ReactION Static" for an instant composition tree parsed straight from your source — no setup required. Diagnostics flag unused components, dead props, and prop-drilling chains, and clicking any node jumps straight to its definition.

Live Analysis

A guided setup wizard auto-detects your dev server and Chrome, then streams a live component graph with a render-count heatmap, per-component "why did this render" reasons, click-to-inspect props/state/hooks, an Initial Load Report, and an on-demand Context provider → consumers map.

About Us

ReactION was born out of an interest in streamlining the React developer workflows, from their inception to release.
We were exceptionally keen to target the demographic of beginner- to intermediate-level developers who are trying to get a better understanding of React’s inner workings (e.g., components, their state data, and mutual inter-relations in the component tree).
In addition, all of us are no strangers to the laborious process of spinning up an external browser to view the fruits of incremental code changes.
With these two concerns in mind, and acknowledging the pervasive use of VS Code among developers, we set out to create an IDE that would allow users to see - in real-time - the visualized component state of their React projects AND the rendered browser output - all within the VS Code development environment.
